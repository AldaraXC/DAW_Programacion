# Ejercicios de Programación en Java - DAW

Este repositorio contiene la colección de ejercicios, prácticas y proyectos desarrollados durante el módulo de **Programación** del Grado Superior en Desarrollo de Aplicaciones Web (DAW). 

El objetivo de este repositorio es documentar mi progresión lógica aprendiendo Java.

## 🛠️ Tecnologías y Herramientas
- **Lenguaje:** Java
- **IDE:** Apache NetBeans
- **Control de Versiones:** Git / GitHub

## 📂 Estructura del Repositorio
El código está organizado de forma modular por temas o unidades de aprendizaje:

- **`/TEMA 1`** - [Introducción a la programación con Java]
- **`/TEMA 2`** - [Uso de estructuras de control]
- **`/TEMA 3`** - [Utilización de objetos]
- **`/TEMA 4`** - [Cadenas de caracteres y Arrays]
- **`/TEMA 5`** - [Desarrollo de clases]
- **`/TEMA 6`** - [Utilización avanzada de clases
